Overview

Way4Tech Logistics & HR Extensions is a complete operational and accounting platform for KSA-based logistics and manpower companies, built on Odoo 19 Community Edition. It replaces a patchwork of separate payroll, fleet, HR, and finance tools with one tightly integrated module that handles everything from worker salary computation to truck investor profit-share and manpower contract invoicing — all posting directly into your Odoo chart of accounts.

📦

Worker Payroll

Excel-based bulk salary import for delivery workers. Auto-computes from platform rules. Posts salary journal entry in one click.

🚚

Fleet & Trucks

Company and investor trucks. Trip invoicing, maintenance tracking, investor P&L, installment financing — all linked to accounting.

👥

Manpower Contracts

Fixed-price and hourly contracts for food delivery and project-based manpower. Timesheet logging, expense tracking, one-click invoice creation.

📄

Commission Receipts

KSA 15% VAT-correct commission invoicing. Creates customer invoice and subcontractor vendor bill automatically.

📊

Profitability Reports

Truck-wise, customer-wise, and salesperson profitability PDF reports. Maintenance history with repeat-repair alerts.

⚙

Full Accounting Integration

Every operation posts a real Odoo account.move (journal entry, invoice, or vendor bill) with analytic distribution.

First-Time Setup

Complete these steps before using any other feature. All accounting entries rely on the accounts and journals configured here.
1

Go to Configuration › Payroll & Accounting Setup

This is the central configuration screen. One record per company. All GL accounts and journals used by the module are set here. If no record exists, create one for your company.

2

Click "Auto-Detect Accounts"

The system scans your chart of accounts by keyword (e.g. "salary", "GOSI", "revenue") and prefills all fields it can match. Review and correct any mismatches.

3

Verify all tabs and save

Check each tab: Payroll, Commission, Fleet & Trucks, Manpower Contracts, Employee Compliance (KSA), and Analytics. Fill any blanks. Save.

4

Set up Platform Configurations (if using Salary Import)

Go to Configuration › Platform Configurations. Create a record per delivery platform (HungerStation, Keeta, Chefz, etc.). Set the fixed salary, minimum working days threshold, per-order rate, and bonus/deduction rules.

5

Add your trucks (if using Fleet)

Go to Fleet & Trucks › Trucks. Each truck can be company-owned or investor-owned. Set ownership type, investor (if applicable), profit share %, and PO limit per trip. For financed trucks, fill the installment section.

2 Platform Configuration (Salary Formula Engine)

Configuration › Platform Configurations

Each delivery platform has its own salary rules. The Worker Salary Import reads these rules to auto-compute pay.

IF working_days >= min_days (default 27): salary = fixed_salary salary += (orders − order_target) × order_adj_rate # positive = bonus, negative = deduction ELSE: salary = orders × per_order_rate salary += petrol_allowance_per_order × orders
FieldMeaning
Minimum Working DaysDays threshold to qualify for fixed salary (usually 27)
Fixed Salary (≥ min days)Base salary paid when days threshold is met
Order TargetExpected daily/period order count — performance benchmark
Per-Order RateRate applied per order when below minimum days
Order Adjustment RateAmount added/deducted per order above/below target
Petrol Allowance / OrderPetrol amount multiplied by orders completed

3 Worker Salary Import

Payroll › Salary Imports

Typical Monthly Workflow

1

Create a new Salary Import record

Set Reference, Period (start/end), Client, and Platform. Click Download Template to get the pre-formatted Excel file with correct column headers.

2

Fill the Excel template (20 columns)

Each row is one worker. Columns cover: employee name, platform code, valid days, orders completed, bonus, petrol allowance, and all performance and office deductions. Save the file.

3

Upload Excel › Import button

Lines are created automatically. Salary is auto-computed from platform rules based on days and orders.

4

Fill from Ledger (optional)

Pulls outstanding advance / deduction balances per employee from the Employee Deductions ledger and pre-fills the matching deduction columns for automatic recovery this period.

5

Review lines — fix any errors shown in red

Rows with validation errors (missing employee, zero net) are highlighted in red. Correct in the import lines list.

6

Mark Imported

Locks lines from further editing. Transitions to Imported state.

7

Post to Accounting

Creates a single journal entry for the entire batch. One debit line per earnings component (salary expense, bonus, petrol allowance). One credit line per deduction type recovered. Net credit to Salary Payable account. Transitions to Done state.

8

Mark Deductions Recovered

Marks all linked employee deduction ledger records as recovered so they no longer appear in future "Fill from Ledger" runs.

4 Commission Receipts

Commission › Commission Receipts

Manages commission invoicing between your company and subcontractors, with KSA 15% VAT handling built in.

Gross Amount (from subcontractor) = A Company Commission % = r Company Commission (ex-VAT) = A × r VAT on company commission (15%) = A × r × 0.15 Subcontractor Net Share = A − (A × r) − VAT
  • Confirm — validates the commission receipt, computes amounts
  • Create Invoice — creates a Customer Invoice (out_invoice) for the full commission + VAT
  • Create Subcontractor Bill — creates a Vendor Bill (in_invoice) for the subcontractor's net share
  • Settle — marks as settled after both documents are posted
Draft → Confirmed → Settled

5c — Investor P&L from Truck › P&L Records button

Gross Profit = Total Revenue − Total Expenses Investor Share = Gross Profit × investor_profit_share_% Company Gross = Gross Profit − Investor Share Indirect Expenses = Yard Rent + Coordinator Salary + Iqama + Other Company Net = Company Gross − Indirect Expenses
  • Create Investor Bill — Vendor Bill (in_invoice) for investor's share
  • Mark as Paid — records payment date on the P&L record

6 Manpower Contracts

Manpower › Manpower Contracts

Contract Types
  • Food Delivery — manpower supplied to a delivery platform (riders, supervisors, support staff)
  • Project Based — manpower supplied for a specific project or site (construction, logistics hub, warehousing)
Billing Types
  • Fixed Price — invoice a fixed monthly amount regardless of hours
  • Hourly Rate — invoice = Total Hours (from Timesheets tab) × Hourly Rate
Key Fields
  • Client — invoice recipient
  • Salesperson — assigned sales rep (used in profitability reports)
  • Analytic Account — tags all invoices and bills for cost-centre reporting
  • Total Invoiced — sum of posted invoice amounts (ex-VAT)
  • Project Margin = Total Invoiced − Total Project Expenses

Tabs

TabContents
Manpower List of assigned employees/workers: name, role, start/end date, daily cost (internal tracking only — not used in invoicing)
Timesheets Daily hours log per employee. Required for Hourly Rate billing — total hours drive the invoice amount. Informational only for Fixed Price.
Project Expenses
(Project-Based only)		 Cost lines: wages, accommodation, utilities, furniture & equipment, transport, other. Each line can generate a Vendor Bill. All bills tagged with the contract's analytic account.
Notes Free-text notes printed at the bottom of the PDF report

Workflow

Draft → Active → Completed
Any state (except Completed) → Cancelled
  • Activate — moves contract from Draft to Active
  • Create Invoice — creates Customer Invoice + 15% VAT at the configured Manpower Income Account. For Fixed Price: uses the fixed amount. For Hourly: uses total hours × hourly rate.
  • Complete — closes the contract; no further editing
  • View Invoices — smart button showing invoice count, navigates to invoice list

7 PDF Reports

📋 Worker Salary Sheet

Accessed via Print button on any Salary Import record. Full table of all workers with every earnings and deduction column, colour-coded error rows, column totals, and total net payable.

📋 Commission Receipt Statement

Full commission breakdown: gross amount, company commission %, VAT, subcontractor net share. Printed from the Commission Receipt form.

📋 Investor Profit Statement

Revenue, expenses, gross profit, investor share %, investor amount, indirect expenses, company net. Printed from the Investor P&L record.

📊 Truck-wise / Customer-wise Profitability Report

Fleet & Trucks › Profitability Reports (wizard)
Select date range, status filter (All / Confirmed / Done / Confirmed & Done), optional truck or client filter, and report type. Outputs: summary table with grand totals + one detailed page per truck/client showing all trips with revenue, cost, profit, margin%.

📊 Investor Aging Report

Fleet & Trucks › Investor Aging Report (wizard)
Outstanding investor payable balances broken down by aging buckets. Identify overdue investor profit payments.

📊 Maintenance History Report

Fleet & Trucks › Maintenance History Report (wizard)
Select date range, optional truck filter, optional category filter. Summary table across all trucks + per-truck detail (reference, date, category, state, vendor, cost). Repeat-category alerts: trucks where the same maintenance category occurs more than once in the period are flagged with a warning badge — helps identify chronic mechanical issues.

📋 Manpower Contract Statement

Printed from the Manpower Contract form. Includes contract details, billing summary, assigned manpower list, full timesheet log with total hours, project expenses (if any), and notes.

📊 Salesperson Profitability Report

Manpower › Salesperson Profitability Report (wizard)
Select date range and optionally filter by salesperson. For each salesperson: truck trip revenue/cost/gross profit/margin% plus manpower contract invoiced/expenses/margin. Summary table + per-salesperson drill-down with full trip and contract lists.

9 Security & Access

RoleAccess Level
Logistics User Read-only on all records. Can log employee deductions. Can run the Excel import wizard. Cannot post to accounting, create invoices, or change configuration.
Logistics Manager Full CRUD on all records. Can post salary batches to accounting, create invoices and vendor bills, activate/complete/cancel contracts, confirm/complete maintenance, and edit all configuration.
Access Control (built-in): The module includes journal backdating protection and vendor creation restrictions. Managers can override; users are blocked from posting to closed periods.
